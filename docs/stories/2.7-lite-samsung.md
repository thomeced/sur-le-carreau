## Story 2.7 — Mode allégé : Samsung en mode « ordinateur », choix mémorisé
En tant que famille qui joue sur une TV Samsung, je veux que le mode allégé s'active quel que soit le réglage du navigateur de la TV, afin que la vague ne déborde plus.

**Pourquoi** : test du 28 novembre 2026 avec la version `2026-11-28a` (story 2.6). Le cadre `?debug=1` affichait toujours « mode allégé : non ». Le user agent n'était plus celui de la veille (`SMART-TV; Linux; Tizen 8.0`) mais `X11; Linux i686 … SamsungBrowser/7.0 Chrome/120.0.6099.5 Safari/537.36` : le navigateur de la TV peut se présenter comme un ordinateur. La détection de la story 2.6 ne pouvait pas le reconnaître.

Parcours rapide BMAD (correctif) : mini-spec, Dev, QA.

### Critères d'acceptation
1. User agent `SamsungBrowser` sans `Mobile` (TV Samsung en mode « ordinateur ») : mode allégé actif, « (TV détectée) » dans `?debug=1`.
2. Téléphone Samsung (Samsung Internet, avec `Mobile`) : pas de mode allégé.
3. `?lite=1` ouvert une fois sur un appareil : le mode allégé y reste ensuite sans paramètre (« (mémorisé) » dans `?debug=1`) ; `?lite=0` l'empêche et efface ce choix.
4. Ordinateur et téléphone récents sans paramètre : inchangés.
5. `tests/lite.js` vérifie 1 à 4 avec les user agents des photos de Ced ; il échoue sans le correctif. Les autres tests passent.

### Tâches techniques
- [x] `js/base.js` : `SLC_TV` reconnaît `SamsungBrowser` sans `Mobile` ; `?lite=1` et `?lite=0` gérés par `localStorage` `slc-lite` (`LITE_MEMO`, `LITE_PARAM_V`).
- [x] `js/main.js` : raison « mémorisé » dans le cadre `?debug=1`.
- [x] `tests/lite.js` : TV en mode ordinateur, téléphone Samsung, mémoire de `?lite=1` (et effacement entre les cas, car les onglets du test partagent leur stockage).
- [x] Docs : architecture §4.4 et §5.1, `docs/test-reel.md` (A3.9), `CLAUDE.md` et sa copie du projet claude.ai, journal, backlog ; `python3 tools/version.py`.

### Notes de réalisation (Dev, 28 novembre 2026)
- La mémoire de `?lite=1` sert de filet : si la TV change encore de user agent, l'ouvrir une fois avec `?lite=1` suffit.
- Tablettes Samsung (Samsung Internet sans `Mobile`) : passent aussi en mode allégé ; sans conséquence visible (panneaux opaques, vague case par case).
- Version `2026-11-28b`.
