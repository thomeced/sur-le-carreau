## Story 0.3 — Version des fichiers (cache de la TV)
En tant que joueur sur la TV, je veux que la TV charge la dernière version du jeu après une mise à jour afin de ne pas jouer avec un mélange d'anciens et de nouveaux fichiers.

### Critères d'acceptation
1. Étant donné une constante `VERSION` (par exemple `"2026-11-24a"`) définie une seule fois, quand `index.html` se charge, alors chaque fichier CSS et JS du jeu est demandé avec `?v=<VERSION>`.
2. Étant donné `editeur.html` et `credits.html`, quand ils chargent des fichiers JS partagés (`categories.js`, `perso.js`, `photos.js`…), alors ils utilisent la même version.
3. Étant donné le pied de l'accueil, quand on l'affiche, alors la version apparaît en petit (utile pour vérifier ce que la TV a chargé).
4. Les tests de 0.1 passent.
5. `CLAUDE.md` indique de monter `VERSION` dans chaque PR qui touche du code.

### Tâches techniques
- [ ] Choisir la mise en œuvre la plus simple compatible avec des scripts classiques : un petit script en ligne en tête de page qui écrit les balises avec `document.write`, ou des `?v=` en dur remplacés par un script `tools/version.py`. Noter le choix dans la story.
- [ ] Appliquer aux trois pages HTML.
- [ ] Afficher la version sur l'accueil.
- [ ] Mettre à jour `CLAUDE.md` et sa copie.

### Contexte dev
- Les images de `assets/` ne sont pas concernées (leurs noms changent quand le contenu change).
- Piège : `document.write` bloque le rendu et est déconseillé ; une version en dur maintenue par un script est plus sûre. Décider en Dev, en restant sans build pour le jeu.
